# MVP03 | Stained Glass Chapel

Open `Scenes/MVP03_StainedGlassChapel.unity` and press Play. Move the flat pixel sprite with WASD or the arrow keys. The camera is an elevated orthographic view of a three-dimensional church interior.

The scene combines point-filtered pixel textures with actual 3D geometry and lighting: stone pillars and pointed arches, pews, a central runner, an altar, stained-glass windows, warm candle lights, and colored spotlights. A 640 x 360 world render is enlarged with nearest-neighbor filtering for a consistent pixel grid. Use **MVP03 > Build Chapel** to regenerate assets and the scene, and **MVP03 > Capture Preview** to write a PNG into the project `Previews` folder.
